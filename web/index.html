01 / Prepare your footage

Creates a new copy. Keeps duration and aspect ratio; pads to fit. Frame-rate conversion drops or duplicates frames; it does not generate interpolated motion.

White keeps the subject. Black removes the background. Match source resolution, frame rate, duration, and frame alignment.

Upload a matte matching your source dimensions: white keeps the subject, black removes the background; a PNG alpha channel is also supported.

Pause the source preview on the matching frame, then click Use preview frame. The frame must be inside the selected inference length. The PNG guides chunks containing that frame and later hint carry; earlier completed chunks are not reprocessed. At its selected frame, the PNG takes priority over carried hints and an optional hint video.

FP32 uses the original CorridorKey checkpoint. INT8 ConvRot uses the converted checkpoint by boricuapab, with quantized linear weights and activations. Missing selected weights download automatically on first use. Foundation models are shared. Quantization can change output quality and performance.

Limited runs start at the beginning of the shot. Seconds use the source frame rate and round up to the next frame. Processing stops at the end of the source if it is shorter.

Smaller chunks use less GPU memory. Larger chunks provide more temporal context. Overlap is set to half the chunk size.

Select footage to see a GPU-based recommendation.

Suggestions are estimates based on currently free VRAM and the selected processing length. Automatic recalculates before inference starts.
