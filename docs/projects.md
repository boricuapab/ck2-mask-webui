# Project sessions

[Feature index](README.md)

Use **Project session** to select an existing project. Enter a name and click **New project** to start another, or **Rename** to rename the selected project.

Sessions automatically save selected footage and hints, model selection, inference length, chunk settings, despill, hint confidence and carry, render history, playback and wipe positions, expanded logs, and scroll position. Restored videos remain paused.

The app checks that referenced media still exists before restoring it. Restarting preserves completed work; interrupted renders and conversions must be submitted again.

Back up the data folders together to preserve sessions and their media. See [Local files](../README.md#local-files) for their locations.
