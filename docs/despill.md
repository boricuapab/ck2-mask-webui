# Despill and green subjects

[Feature index](README.md)

**Despill strength** controls additional green suppression from **0% (off)** to **100% (full)**. The default is **50%**.

For green paint, reflective cars, or other intentionally green subjects, start at **0–10%**, or click **Off / preserve greens**. Stronger despill can remove legitimate green color from the subject.

Despill affects the checkerboard preview and transparent cutout. The alpha matte and raw foreground exports remain unchanged. See [output files](outputs.md) for the available formats.

The setting persists per project and is captured per render in history and logs. Submit a new render to apply changes; existing results remain available. Disabling despill does not recover subject detail already lost in the model's matte.
