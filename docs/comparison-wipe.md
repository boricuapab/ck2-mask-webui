# Input/keyed comparison wipe

[Feature index](README.md)

Each checkerboard result preview includes a wipe with the **original input on the left** and **keyed result on the right**.

- Drag the divider to reveal more of either video.
- For keyboard control, focus the divider and use the arrow keys.
- Use **Play/Pause** and the playback-position slider to control both videos together.

Playback and seeking stay synchronized within the rendered duration, including when only part of the source was processed. Wipe and playback positions are saved per project; restored playback remains paused.

The comparison uses the source belonging to that render, even after you select different footage. Older renders can recover their source when it can be identified uniquely. If the original is missing or ambiguous, the keyed preview remains playable and downloadable.
