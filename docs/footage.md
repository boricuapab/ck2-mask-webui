# Source footage

[Feature index](README.md)

Choose a video from **Local clip library**, or use **Or upload a source video**. To populate the library manually, place clips in `inputs/` beside the application.

The source preview displays the selected footage, with its dimensions and frame rate. Uploads are saved locally in an ID subfolder to avoid filename collisions and are recalled with the project.

Use [footage conversion](conversion.md) to prepare a different resolution or frame rate. After converting, click **Use converted footage** to select the converted copy for inference.

Selecting a source does not submit a render. Configure the remaining settings and click **Process on GPU** when ready.
